## 운영 규칙

- **주기**: 매일 1회
- **분량**: **채택 기준을 통과한 것만, 최대 10건** (2026-07-25판부터. 고정 TOP 10 폐기 — 채우기용 끼워넣기 방지)
- **정렬**: 채택 등급(S→A) 우선, 그 안에서 근거가 공개된 편집 주목도순. 측정 시점과 지표 종류를 함께 표시하며, 추정치는 사실처럼 쓰지 않음
- **조사 범위**: 리포트 날짜 기준 최근 30일
- **형식**: 요약 순위표(등급·라이선스 컬럼 포함) + 트렌드별 상세(설명, 인기도 근거, 출처 링크) + 스택 시사점

### 채택 기준 (2026-07-24 확정) → [ADOPTION-CRITERIA.md](ADOPTION-CRITERIA.md)

**지금 바로 안전하게 붙일 수 있는 것만** 추천한다. 하드 게이트 4개를 하나라도 걸리면 제외:

| 게이트 | 제외 |
|---|---|
| **보안** | 알려진 CVE·샌드박스 탈출 이력, 광범위 자격증명 요구, 이중용도 공격도구, **서명 없는 실행 파일 동봉**(스캔은 저장소가 아니라 **계정 단위**, 2026-07-31 개정) |
| **비용** | 유료·크레딧 소진형·무료티어 만료형 |
| **라이선스** | GPL/AGPL/상용/독점, **라이선스 불명**. 통과 목록은 **산출물 유형별**(2026-07-31 개정) — 코드는 MIT·Apache-2.0·BSD·ISC, **문서는 여기에 CC0-1.0·CC-BY-4.0 추가**(단 NC·ND·SA는 제외) |
| **설치 부담** | 별도 바이너리·서버·Docker 설치 필요 |

기준이 개정되면 **개정 전 기준으로 제외했던 과거 항목을 다시 판정**하고 결과를 [RE-ADJUDICATION.md](RE-ADJUDICATION.md)에 남긴다.
과거 리포트는 날짜 스냅샷이므로 수정하지 않는다.

통과분은 등급을 매겨 **S(이식형 스킬·설정, 설치 0) → A(무설치 활용)** 순으로 싣는다.
**S가 최우선.** 설치가 필요한 B등급은 원칙적으로 제외하며, "쓰던 게 EOL이라 갈아타야 한다" 같은
**의사결정 정보**일 때만 `[설치 필요]` 표기와 함께 예외로 싣는다.
